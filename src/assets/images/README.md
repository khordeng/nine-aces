# Photos

Drop a photo here with the right name and it shows up on the site. No code changes needed.

| Where it shows | File |
|---|---|
| Menu: Main course | `menu/main-course.webp` |
| Menu: Additionals | `menu/additionals.webp` |
| Menu: Beverages | `menu/beverages.webp` |
| Menu: Snacks | `menu/snacks.webp` |
| Menu: Cigarettes | `menu/cigarettes.webp` |
| Menu: Gloves | `menu/gloves.webp` |

- Any of `.webp`, `.jpg`, `.jpeg`, `.png` works. Large phone photos are fine: the build resizes and compresses them.
- Menu photos: portrait 4:5, at least 1200 x 1500 px.
- Keep plates and faces in the middle 70% of the frame. On phones the photo is cropped to 16:9.
- Dark, warm lighting matches the site.
- Run `npm run check:images` to see which slots are filled.
